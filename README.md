# Household Water Consumption Prediction

## Project Overview
This project predicts household water consumption using machine learning.

## Dataset Source
The dataset used in this project was obtained from GitHub:

Household Water Consumption Pattern:
https://github.com/Harshita1375/Household_water_consumption_pattern

## Models Used
- Linear Regression
- Decision Tree Regression
- Random Forest Regression

## Results
Random Forest:
- MAE: 11.79
- RMSE: 18.26
- R² Score: 0.940
